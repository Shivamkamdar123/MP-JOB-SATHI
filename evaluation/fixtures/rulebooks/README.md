# MPESB / PEB Exam Rulebooks

These 9 PDFs are official Madhya Pradesh Employees Selection Board (MPESB / formerly PEB) exam rulebooks (परीक्षार्थी नियम पुस्तिका).

## Distinguishing Document Types
- **Recruitment Advertisements / Notifications (`evaluation/fixtures/pdfs/`):** Short announcements with vacancy counts, eligibility criteria, application window dates, and fee schedules. These are the primary target for extraction in MP Job Saathi.
- **Exam Rulebooks (`evaluation/fixtures/rulebooks/`):** Comprehensive multi-page regulatory documents containing syllabi, examination center rules, normalization formulas, and general exam administration procedures.

These rulebooks are preserved here as reference fixtures for exam pattern and regulatory rule parsing, but are separated from recruitment notice extraction evaluation so as not to distort recruitment field recall and accuracy benchmarks.
